How it runs

  • Read-only. Every command is a show or a configuration get.
  • Two passes. First it lists what a management station manages and writes a scope file of serial numbers; then it collects against that file. The scope file is plain text, so they can edit it or you can send them one.
  • Resumable. A collection can take a while. If it is interrupted, running it again picks up where it stopped.
  • The certificate is shown before any password. Untrusted is expected on a management interface; it is displayed in full and confirmed first, then pinned by thumbprint.

Worth telling them

  • Windows PowerShell 5.1, which ships with Windows — nothing to install.
  • The script is unsigned, so the .cmd launcher is what gets it started. If their execution policy is set by Group Policy, nothing will run it and they will need to tell you.
  • The archive is not encrypted yet. Agree how it comes back before they send it.
